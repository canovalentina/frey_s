# Artist Guide — Uploading Your Music to frey_s.com

Hi Federico! This document explains everything you need to prepare so your tracks can go live on the licensing section of your site.

---

## Overview

For each track you want to sell, you need to provide:

1. **Two audio files** — a short preview clip and the full track
2. **A filled-out track info sheet** (template below)
3. **Cover art** (optional but recommended)

That's it. Once you hand these over to your developer, they'll upload everything and publish the tracks.

---

## Part 1 — Audio Files

### File 1: Preview Clip (required)

This is what visitors hear before buying. It plays on the website directly.

- **Length:** 30–45 seconds (a representative section — usually the most evocative part)
- **Format:** MP3, 192kbps or higher
- **Watermark:** Add a subtle audio watermark so it can't be used without purchasing. The easiest way:
  - Open the file in **Audacity** (free: audacityteam.org)
  - Record yourself saying *"frey_s preview"* softly, or use a short tone
  - Overlay it at low volume (around -20dB) somewhere in the middle of the clip
  - Export as MP3
- **Filename:** `[track-slug]-preview.mp3` (e.g. `silent-cartography-preview.mp3`)

### File 2: Full Track (required)

This is what the buyer receives after purchasing.

- **Format:** MP3 at 320kbps **AND** WAV at 24-bit / 44.1kHz (two separate files)
- **Length:** Full track, no watermark
- **Filename:** `[track-slug]-full.mp3` and `[track-slug]-full.wav`

### File 3: Stems (optional — for Professional license only)

If you have stems available for a track, zip them all into a single archive.

- **Format:** ZIP containing individual WAV stems (kick, bass, melody, etc.)
- **Filename:** `[track-slug]-stems.zip`

## Part 2 — Track Info Sheet

Copy this template and fill it out for each track. Send one sheet per track.

```

─────────────────────────────────────────

(The display name. e.g. "Silent Cartography")

(A URL-friendly version of the title — lowercase, hyphens instead of spaces, no special characters.

Duration:
(e.g. 3:07)

BPM:
(Tempo. e.g. 72. Leave blank if you're unsure.)

Key:
(e.g. C minor, G major. Leave blank if unsure.)

(Describe what's in the track. e.g. "Solo piano with light ambient electronics and field recording")

Moods (pick 2–3):

Stems available:

Short description (1–2 sentences, optional):
(This appears on the track page. e.g. "A slow piano meditation recorded at dusk in Barcelona.")

─────────────────────────────────────────

```

## Part 3 — Cover Art (Optional)

Each track can have its own image. If you don't provide one, it will use a generic placeholder.

- **Format:** JPG or PNG
- **Size:** at least 800 × 800px, square
- **Filename:** `[track-slug]-cover.jpg`

---

## Part 4 — How to Send Everything

Once you have the files and the info sheets ready, send them to your developer via whichever method you prefer:

- **Google Drive / Dropbox** — create a shared folder with all the files and a document with the filled-in info sheets
- **WeTransfer** — good for large audio files
- **Email** — fine for 1–2 tracks if the files aren't too large

Suggested folder structure:

```
frey_s-tracks/
  silent-cartography/
    silent-cartography-preview.mp3
    silent-cartography-full.mp3
    silent-cartography-full.wav
    silent-cartography-stems.zip   ← if available
    silent-cartography-cover.jpg   ← if available
    info.txt                       ← your filled-in info sheet
  analog-pastoral/
    ...
```

---

## Part 5 — After You Send the Files

Once your developer receives everything:

1. They upload the audio files to cloud storage
2. They enter your track info into the admin dashboard
3. They set the track to **published** so it appears on the site
4. You'll get a link to review it before it goes live

Tracks are **not visible to the public** until published — so you can send files in batches and review each one before launch.

---

## Tips

- **Start with 3–5 tracks** to test the licensing flow before uploading everything
- The **preview clip matters most** — it's the first thing a potential buyer hears. Pick a section that represents the mood of the full track
- Tracks in **multiple genres and moods** get discovered by more filters — be generous with tags
- If a track doesn't fit neatly into the mood/genre options above, just write it in under "other" and your developer will add it
